## 実況の合わせ方（読み上げない）

- MOMO＝「モモ」、SORA＝「ソラ」。名前と短い動詞を中心にして、説明は動きが落ち着いてから入れる。
- 「取りました」は、回収カウンターが増えた瞬間に合わせる。台本の時刻を優先しない。
- 通常速度では全実況を詰め込まない。接近・回収の詳しい実況は、明示付きのスローに載せる。
- 「考えた」「喜んだ」「安全を理解した」など、画面から確認できない内面は断定しない。
- 「危険を避けた」は、経路が実際に見える場合だけ。今回の台本は回収だけを実況する。
- NGは過去の実装の実映像。修正・追加学習を挟んだ別実行であり、単なる再試行で直ったという編集にしない。
- 途中で止まった場合：「ここで止まりました。入力と状態を確認します。」見えていない原因を即断しない。
- 生収録で回収順が変わった場合は名前を入れ替える。以下の証拠は保存済み映像の順序であって、今後の実行の保証ではない。

## 実映像との対応

- NG：`foraging-behavior-review.md` に記録した未学習MOMOの右方向への偏り。
- 再挑戦：`artifacts/presenter-long/gui-evidence.json` の `clips.behavior`。保存済み実行ではMOMOがtick 31、SORAがtick 37で回収し、終了時は各1個・衝突0。SQLiteの行動結果と照合済み。
- 結果表：`foraging-validation.json`。回収24/24、直接入力23/24、安全基準未達。生物固有の優位は未確定。
- 市場：検証済みの別収録。署名はEOAなので、現在の実装を「スマートウォレット実装済み」と呼ばず、「ウォレット連携の拡張例」と呼ぶ。
- 説明する順序は物語上の構成であり、「NGの後に初めてプロトコルを実装した」という開発時系列は主張しない。

MaleCNSは「メイル・シー・エヌ・エス」。正式なデータセット名は `male-cns:v1.0`。提供されているのは神経接続データであり、今回の行動モデルそのものではありません。動的計算、感覚入力、行動出力は本プロジェクトの実装です。

冒頭にデータ名と出典URLを表示し、最後の設計図に[動画クレジット](video-credits.md)を10秒以上表示します。出典は動画内に焼き込み、英語字幕と重ならない位置に置きます。

図の数値は説明用の例で、実測の再生ではありません。[アニメーションと読み上げの対応表](animation-cues.md)に、処理の出典とハードウェア確認結果を記載しています。GPUは搭載されていますが、この学習・推論はCPU実行です。
