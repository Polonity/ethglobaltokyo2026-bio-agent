[機械可読の検証記録](evidence/full-local-acceptance.json)に、出典hash、実行モデルhash、GUIソースhash、時刻と実測値を保存した。

## 再確認

データ準備は[全規模モデルの手順](../design/malecns-full-local.md)を参照。専用サーバーが起動していない場合:

```bash
npm run full:dev
```

別ターミナルで:

```bash
npm run verify:full
```

GUIは http://127.0.0.1:8810/ 。「連続実行」を押し、刺激スライダーを操作する。「停止」で計算を止める。受入試験自体が状態とcheckpointを変更するため、自分の試行を残す場合は別の状態ファイルへ退避してから実行する。

詳細な実行結果とスクリーンショットは `artifacts/malecns-full/` に生成される。`npm run full:benchmark` と `npm run full:scaling` で計算速度・縮小版比較も再測定できる。環境負荷で速度は変わる。

## 今回の判定

ローカルで全規模を維持できたため、**現時点で7神経へ戻す必要はない**。以前の縮小はブラウザーの接続検証を早く行うための実装上の判断であり、他の神経が不要という研究結果ではなかった。今後削減する場合も、この全規模モデルを比較の基準として残す。

この達成範囲は全分類付き神経の計算実験である。全セグメントを含む再構成、神経伝達物質の符号を含む生物学的再現、全規模モデルでの3用途の学習・オンチェーンアプリ統合を達成したという判定ではない。既存の軽量アプリは別経路として維持する。
