# 表示言語（i18n）

ヘッダーの言語選択で「システム / English / 日本語」を切り替えます。初期値はシステムです。

| 選択 | 解決される言語 |
| --- | --- |
| システム | ブラウザーが示す `navigator.language` が ja / ja-* なら日本語。それ以外は英語 |
| English | システム設定にかかわらず英語 |
| 日本語 | システム設定にかかわらず日本語 |

ブラウザーはOSと異なる言語設定を持つことがあります。「システム」はブラウザーがWebページへ公開する言語を使用します。

選択値はlocalStorageの `fly-lab.language` に `system` / `en` / `ja` として保存します。実際に解決された言語ではなく選択値を保存するため、システム設定変更にも追従できます。保存できない環境では現在のタブ内だけで切り替えます。

## 対象とデータの境界

画面本文、操作ラベル、アクセシビリティ用ラベル、接続・送信状況、取引詳細、学習結果、イベント表示、Canvasの吹き出しを翻訳します。既存の技術表記・固有名詞は必要に応じて維持します。

言語を切り替えてもレース・選択個体・未送信の入力・送信処理はリセットしません。Tx hash、Registryアドレス、イベント名、モデルID、Agent名、revision、JSONの出力形式を変更しません。履歴の翻訳は表示だけで、保存用の元イベントには影響しません。

## 実装

- `apps/frontend/i18n.js`: 言語解決、保存、翻訳、DOM表示の切替。
- `apps/frontend/messages.js`: 日本語の原文と英訳、可変値を含む文のテンプレート、日本語化する英語ラベル。
- `apps/frontend/app.js`: 描画境界で `translateDOM()`、Canvasの吹き出しで `translate()` を使用。

DOM翻訳は元のテキストと属性をWeakMapで保持し、翻訳済み表示から逆翻訳せずに戻します。入力値やイベントハンドラーを作り直しません。未知の文字列は元の文字列を表示するため、外部RPCが返す未知のエラーは原文が残る場合があります。

追加文言は辞書にも追加します。動的な文は `{name}` 等のプレースホルダーで登録し、イベントやモデルの内部値を翻訳済みの文字列に置き換えないでください。技術情報や言語名を翻訳対象から外す場合は `data-no-i18n` を使用します。

## 検証

```sh
# 辞書・言語解決の単体検証（サーバー不要）
node --test tests/i18n.test.mjs

# Anvil + Workers起動後、実ブラウザーで検証
npm run test:i18n
```

ブラウザー検証はローカルAnvilへ刺激を1件送信します。`test:local` や録画と同時実行しないでください。

確認項目は、英語／日本語のシステム既定、未対応言語の英語フォールバック、明示選択、状態保持、リロード後の保持、開いた取引詳細の切替、学習状況、英語表示の日本語漏れ、スマートフォンの横はみ出しです。成果物は `artifacts/i18n/`。

既存の日本語ブラウザーテストと字幕付き録画は `locale: ja-JP` を指定しています。これは製品のシステム既定値を変える設定ではありません。
