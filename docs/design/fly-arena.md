# Fly Lab: 競争と自己学習の GUI

状態: **Cloudflare Workers 公開済み / ブラウザー内 Runtime**。

公開 URL: https://ethglobaltokyo-bio-agent-arena.commun-official.workers.dev

## 体験

12体が90秒のラウンドで蜜の獲得数を競う。蜜の位置は共有され、誰かが獲得すると別の場所に出現する。危険領域に入ると報酬と体力が減る。

ユーザーは活動モード（採餌・探索・休息）、危険刺激の強度、エネルギー供給を変えられる。フィールドのクリックで蜜を置き、ハエまたは順位行のクリックで対象を観察できる。速度変更、一時停止、手動学習、学習の自動選抜、実験 JSON 保存も提供する。

18秒ごとに採餌効率（蜜の数 / 競争に参加した tick 数）が低い個体を最大2体選び、8秒間の学習へ移す。直近28秒以内に学習した個体は再選抜しない。学習中は競争から離れ、得点を得ない。ラウンド終了直前は自動選抜を止める。

## 判定と学習

実装: `packages/bio_agent/browser/arena.js`、モデルID: `foraging-q-v1`。

1. **観測**: 最も近い蜜の方向（8区分）、次の移動で危険または境界に入る方向（8bit）、低エネルギーかどうか。
2. **判定**: 状態別の9個の Q 値から8方向移動または休息を選択。探索率は個体ごとに異なり、刺激強度でも変わる。
3. **行動**: 移動、採餌、休息。低体力では速度が下がり、極端な枯渇時は休息する。活動モードは探索・休息の選択傾向を変える。
4. **報酬**: 蜜へ近づくことで小さな正報酬、採餌で+5、危険領域で負報酬。移動の時間コストと低体力時の休息報酬も含む。画面の順位はこの報酬ではなく実際の蜜の数。
5. **学習**: 各個体は直近300遷移を記録する。学習室で自分の経験を再生しつつ、専用の練習環境を探索する。学習率0.09、割引率0.6の Q-learning。8秒のシミュレーション時間で3840練習遷移を処理し、経験がある場合は同数のリプレイ更新も行う。
6. **選別**: 学習に使わない固定3コースで新旧の方策を同条件・探索なしで比較する。平均報酬が0.01を超えて改善した場合のみ採用し、policy version を上げる。それ以外は既存方策を維持する。
7. **復帰**: 成績にかかわらず学習後に競争へ戻る。エネルギーは最低65%まで回復する。これは休息の効果であり、学習の改善とは別に扱う。

初期 Q 値には蜜の方向を好む弱い事前値がある。学習は実際に Q 値を変更するが、毎回改善するとは限らない。固定3コースは反復してモデル選別に使う**検証セット**で、独立した最終評価や一般的な学習性能の証明ではない。

## 実行とデータ

- Runtime はブラウザー上で5Hz、描画は requestAnimationFrame。順位とパネルは約4Hzで更新。
- 同じ seed・同じ tick と入力操作ならモデルの推移を再現できる。アニメーション用の羽ばたきは判定に影響しない。
- タブごとに独立した競争。ページを閉じてもサーバーで走り続ける構成ではない。
- 次ラウンドは採用した方策と経験を引き継ぐ。再読込で初期化する。
- JSON 保存は現在の方策、直近の経験、直近40件のイベント、評価結果、seed とワールドのスナップショット。完全な履歴再生や中断再開の形式ではない。
- Workers は公開アセットと `/api/health` を提供する。Python の SQLite Backend はこの GUI の状態を保存しない。

## 境界と次の接続

MaleCNS 回路はまだ読み込んでおらず、生物学的学習の実証ではない。画面にもモデル種別と未接続状態を表示する。Sepolia Registry は未デプロイで、入力はブラウザー内のローカル Status 操作である。

既存の [イベント駆動設計](runtime-and-events.md) は次段階の構成。将来の共有 Runtime と永続化、チェーンイベント入力、MaleCNS モデルは、今回のブラウザー用 Runtime と区別して実装・検証する。Cloudflare 用の秘密情報を GUI へ渡す必要はない。

## 検証

- `npm run test:arena`: 競争、再現性、方策変更、採用条件、一時停止、入力、ラウンド引継ぎ。
- `npm run test:browser`: 実 Chrome で移動、刺激変更、学習復帰、下位選抜、ダイアログ、JSON保存、ラウンド更新、モバイルの横はみ出しを確認。
- `ARENA_URL=... ARENA_ARTIFACTS=... npm run test:browser`: 公開サイトにも同じ確認を実施可能。
- スクリーンショットと検証記録は `artifacts/` に保存し Git には含めない。
